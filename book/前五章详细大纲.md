# 《朝廷让我验妖尸，我验出了自己的死期》｜前五章详细大纲 v1

> 这是**待写作的剧情任务书**，不是小说正文或已经发生的事实。预计每章约9,000汉字，允许8,000—10,000；本表按场景/视角/动机/线索/反转/情绪后果给出可执行预算，写作时不必机械逐字照抄。第一章正式起笔需重新做 V4.3 brief-check 和发布前检查，不可把大纲当成已审正文。

## 总体时限、反派棋局及推理标准

- 事件从**景和十七年四月初九酉初**至**四月十一酉前**，约两昼夜；岑溪县衙→北仓→柳家纸铺→县审堂，地点在县内，徒歩/马车耗时可核对。县尉许抱山收到的半幅斩令只有一枚公印，另一个合法签押要从雍州府经驿递补达。真正第三日死期是斩令拟执行时间，而非预知命运。
- 首案死者杜千衡为北仓书吏，因抄错玄籍发现被人用假妖籍转运人犯。凶手先迫使杜千衡说谎并用嫁忆材料让他的末谎感知包含「斩首谢惊弦」的预演画面，之后毒杀、缝回声丝，利用县衙验尸规程把谢引向指定结论。为什么必须点名谢，暂不由前五章给最终答案。
- 真凶的前五章可动资源：仓库封存钥匙、账册焚毁、一次性回缝丝、加急半幅斩令、巡卒四名、两名仍可能反水的知情者；**不能**在远方无成本监控所有对话。裴照微可以依法封尸、停审，不能未经复核就改掉既有斩令。
- 线索层级：A现场可见（黑丝、印泥、伤口、封条、时间）；B来自独立物证比对（账纸墨色＋押印程序）；C证人口述（受胁迫可能失真）；D死者主观末谎画面（可被嫁忆篡改）。决定性暂缓必须建立在A/B链，不靠D。
- 第5章「三日斩令」危险要有实质结果：**暂缓斩决、留押候审、关键证人存活**。首案可留到第10章，但不能只用更大悬念冲掉兑现。

## 第01章｜验尸房里有人叫我的名字

**预计9,000汉字；第1日酉初—亥初；全章谢惊弦贴身第三人称；目标：活着完成验尸，不让尸体被认作自己碰坏。**

1. **0—1,200字｜醒尸与封门（约1,200）**：雨夜县衙验房，一具封为异尸的仓吏杜千衡忽然睁眼，僵硬地说“你不是今天该死的那个”。写尸口干燥气音、手指刺墨、封条折角，与尸房值役惊慌。前800汉字必须出现醒尸点名。谢惊弦先用封布固定尸身，不徒手惊动可疑部位；另一个小吏想立刻上报“妖尸诈起”，制造失去调查控制权的危机。
2. **1,200—3,000字｜期限与代价（约1,800）**：谢发现喉部黑灰细丝、可见缝针下有早于死后的瘀痕；为了在上官到场前保存线索，检验瞳斑/喉索/妖纹，第一次主动触发「末谎」。片段仅十息：尸者最后一次明知说谎时看见的刑台，写着“三日后”的斩令一角，被斩者衣袖有谢家旧缝，画面中的“谢惊弦”低着头；不由叙述者断言这是真未来。能力过后，谢能指认父亲教过自己一套结绳法，却再想不起那天下午父亲手掌的温度/声音与现场画面；他急写封条「M01」自证失去而不是无损开挂。
3. **3,000—5,100字｜谁把名字写进尸口（约2,100）**：何砚生赶来，不听鬼话，检查黑丝遇热收缩；谢提出“机关能作声”，并对比尸咬合方向与活体说话不同。老仵作要求按规程记录时辰和施检次序，防止官府指其弄尸。谢隐瞒能力来源，只说死前疑有强迫施术，造成师徒信任的第一道裂缝。
4. **5,100—7,200字｜截断验状的官符（约2,100）**：县尉手下来接尸，出示异尸快速焚化令。谢以舌根活体擦伤和尸缝证据争取暂缓，发现快焚令抄写的案号不同于尸状表面案号。县尉手下有职业逻辑：怕尸变、急于按上命处理，并非逢主角必失智。
5. **7,200—9,000字｜最后一行字（约1,800）**：验房外短暂隔离时，谢在送来的半幅斩令影抄上认出自己的名字，签押时刻是三日后，送令骑手已上路。何砚生提醒“谁拿这东西给你看，谁就要你先乱”。谢选择不逃，先封存黑丝，留给读者“看见未来”是否有人造假的猜疑。

**本章证据／知情范围**：I03 黑丝 A；I04 斩令影抄 A（真实性尚未证）；末谎画面 D；M01 遗失父亲教结绳经历（主角主观，待何砚生/实物交叉）。谢知道被针对但不知道凶手；何砚生仅知道尸声有人工痕迹。**章节永久后果**：首次异能失忆、谢被列入当晚重点看管。**结尾问题**：有人先在一具死者的谎言里安排他死，再把斩令送来，谁能同时碰到尸体与官符？

## 第02章｜死人的最后一句谎话

**预计9,000汉字；第1日亥初—第2日卯时；目标：不再相信画面本身，保存可在公堂复验的证据。**

1. **0—1,700字｜封尸的代价（约1,700）**：谢按衙门登记封缝线、取一寸黑丝、留半寸作法检对照。何砚生要求交出主笔权限；谢宁愿被记过也坚持让另一验吏在封条上签名。性格冲突不是谁凶谁错：老仵作怕徒弟用不合法程序葬送证据。
2. **1,700—3,600字｜以实物反驳尸语（约1,900）**：查舌根擦伤、咬痕及尸房通风孔，推断「尸声」需要预先缝丝，且未必包含活人的意志。对照第一章片段中的行刑人左手执刀、斩令贴在木背而非官案正面，和实际斩台法度不符。谢只能记下疑点，不能凭记忆一口说成有人拍戏。
3. **3,600—5,700字｜杜千衡生前的最后一夜（约2,100）**：走访抬尸的更夫与仓口值夜者，分别记录谁亲见、谁听人传话。得知杜先抱着册页逃离北仓，后来却主动说“我没见过那张册”，这可能是末谎触发句，但未经证实。谢为保护其中一个害怕丢饭碗的更夫，许诺不给他暴露姓名，却令证据暂时无法在审堂使用。
4. **5,700—7,400字｜一张提前写好的单子（约1,700）**：夜值班书吏送来尸体转交凭证，其笔迹写好的是“明日寅时已焚”而当下尚未到寅时。谢借灯比对墨色、字压，留出“模板抄错”合理解释，并拍板要去北仓核对账簿留痕。
5. **7,400—9,000字｜两种死法（约1,600）**：何砚生推断杜死于毒而非妖反噬，关键死因缺少药物样品；此时北仓门前有人投来黑灰纸团，提醒「管好你的父债」。谢选择先保样而非追人，为行动选择付出错过抓人的代价。

**新增线索**：舌根擦伤和喉丝 A；行刑画面与本县规程不符仅是假设；提前填的尸交凭证 A；更夫证词 C；父债纸条来源不明。**角色推进**：何砚生开始担忧徒弟隐瞒；谢学会把“末谎告诉我”换成第三者可验的结论。**结尾问题**：为何还未焚尸，官府的尸移交单却先写了“已焚”？

## 第03章｜斩令比人先到

**预计9,000汉字；第2日辰时—未时；目标：抢到可供公开验状复核的一道合法程序。**

1. **0—1,500字｜持令而来的四个人（约1,500）**：押解校尉施元定带半幅斩令入县，指示先羁押谢。县尉许抱山认为小县负担不起妖案失控，按文书行事；谢提出名册中日时、案号与尸状不一致，要求看签押底卷被拒。展示执行者的命令与责任，并非兵丁一听主角推理就反水。
2. **1,500—3,500字｜一枚少掉的印（约2,000）**：县衙吏典说明该类斩令需县、府双签押，押解队带来的是“先羁候补”的甲半令，不足以立即处决。谢发现影抄印泥含非本县朱砂颗粒，何砚生可以提供对照。避免编造现实朝代法律，明确这是大昭故事制度的流程。
3. **3,500—5,300字｜稽核官裴照微（约1,800）**：裴以巡妖司稽核官身份例行查杜尸登记，怀疑谢擅自取样；她拒绝听“尸体告诉我”的不可验说法，却承认封条上的两个独立签名和异常墨色值得查。她的私事：上月调查的同僚在类似档号下失踪，**对主角不公开**。
4. **5,300—7,300字｜交换条件（约2,000）**：谢以自己的验吏身份与尸样交接记录交换复验时间，裴要求他签署“留县不得逃”的限行约。许抱山因责任压力同意一天限时，并提出证据必须于第3日卯时前送审。谢没有获得特殊免死特权。
5. **7,300—9,000字｜快马尚在路上（约1,700）**：驿站报第二签押已派快马，可能在斩令所标时间前抵县；同时北仓账簿被借出。谢与裴分头行动，裴去官方印房，谢寻非官面纸张证据，互相对对方有保留。

**新增线索**：签押缺位 A、印泥材料差异 B待复核、驿递时程 A、失踪同僚 P02私有线索不透露给谢。**阶段收益**：获得24小时复核窗和一份程序性限制，读者看见一次依靠证据而非蛮力赢得的主动权。**结尾问题**：这份只有半边的令已经足够困住他，另一半是谁在赶送？

## 第04章｜纸灰上的第二枚官印

**预计9,000汉字；第2日申时—第3日寅时；目标：拿到法庭能收的北仓纸证，并守住知道账目的人。**

1. **0—1,700字｜纸铺的旧账（约1,700）**：谢带着尸交单的纸屑找柳青栀。柳能凭纸纤维和旧纸行防伪水线看出这批“今年官纸”出自停产旧模，但纸样本身不能指认是谁伪造。她要求救弟弟的案件线索做交换；谢不能立刻许诺越权改案，仅答应共享合法可公开的抄本。
2. **1,700—3,500字｜北仓走访与证词成本（约1,800）**：更夫指出杜千衡的工作桌上曾有两种不同账页；第二证人是配货女工聂小雀，确曾看见有人把“人名”改作“妖名”，但她只见侧面、不认得脸。追兵可能不是为灭口而先夺证人家的粮票，制造真实胁迫。
3. **3,500—5,700字｜焚档现场（约2,200）**：北仓起火，众人分工救人、抢卷、封住出火口。谢先救聂小雀的幼弟，导致大部分账册烧毁；柳保存灰烬中半页印色，裴控制官方封存。没有“不烧坏”的奇迹密档：仅余半页数字、纸水线和一个押记可比对。
4. **5,700—7,500字｜隐瞒的代价（约1,800）**：聂说出改名时辰，却承认自己偷过仓粮换药，怕出庭被判，谢选择把这件不利事实也记录以免证词日后被推翻。柳的铺子被巡卒查封为“涉假印纸”，合作带来真实财产损失。
5. **7,500—9,000字｜往审堂跑（约1,500）**：裴指出两枚印不是同一批朱砂，其中一个疑出府司备用印盒；证据足以要求审堂暂缓，但复核期限将至。雨夜一行人携封条、灰页、活证人分两路进县城，结尾是驿骑已经叩响府衙外门。

**新增线索**：老模官纸 B、半页账与灰烬A、聂的有限证言C；官方封存链「谢→柳观察→裴封存→审堂」需记录各自权利与接触时刻。**情绪余波**：救人损失资料、柳店铺被封、聂不得不承认偷粮。**结尾问题**：救出的三件证据是否能比第二枚印先到审堂？

## 第05章｜斩首前三刻

**预计9,000汉字；第3日卯时—酉时前三刻；目标：在公开程序中阻断斩令，并确认真正的战争才开始。**

1. **0—1,600字｜两个堂口的规矩（约1,600）**：县衙临时审堂与巡妖司稽核桌并设，许抱山按时令负责执行，裴照微依法只可申请暂缓，不可消灭密令。谢因受控不能主讲全部证物，需借何砚生和聂小雀独立陈述；突出他身份低微的制度障碍。
2. **1,600—3,500字｜先拆掉妖尸证据（约1,900）**：何砚生复验杜舌根与回缝丝，证明能人为制造醒尸音；并明确“这只能证明被摆弄，**不证明**谢无罪”。敌方拿出谢私自取样违例，促使主角交出封条实物供第三者检验，冒着自己受罚风险。
3. **3,500—5,500字｜纸证交叉（约2,000）**：柳以纸水线说明尸交单/半幅斩令有旧纸模来源，裴比对印泥与当日府文书颜色差异；聂证实杜改账当晚曾被押走，但拒绝指认未亲见的幕后人。对方提出“备用印合法借用”“误领旧纸”的可行反解释，审堂只能审到**签押程序被严重质疑**，不能草率判所有人有罪。
4. **5,500—7,100字｜三刻之前的选择（约1,600）**：驿递补印将至，许抱山要求照旧羁押。裴为阻断立即斩决，依据“异尸验状封存缺核＋斩令双押尚未完整在卷”的两项事实提出暂缓呈请；必须有书面回执与二人见证，而不是主角声泪俱下就被释放。
5. **7,100—9,000字｜命留下，名字没清（约1,900）**：暂缓令盖下，谢从刀下活下来，却由县狱转入府司押查，不能自由远走；何砚生为替徒弟出证失去验房主验权，柳的铺子仍被封。裴拿到一张被烧卷的府司档号，发现它与她失踪同僚经手卷号前缀相同，但暂不把完整线索交给谢。最后有人带着杜千衡尸档的异本离县，**首案仍须在第10章结算**。

**兑现与代价**：H02 「三日必斩」被有证据地阻断，是具体胜利；谢失去自由、师徒与柳付出代价。H01/H03/H04 留到章6—10，明确剩余问题。**读者下一问**：为害死一个仵作，为什么连县、府两级印信都可以拿来做局？

## 写作前统一检查卡（必须在创作对应章时重新填写）

- [ ] 尸体回声与末谎画面按 canon 规则，第一卷不得开启未来预言能力；一尸最多一次。
- [ ] 记忆代价 M01 要写成可观察的生活缺口，并在后续章保持效力。
- [ ] 前800/3000汉字是编辑自检线，不假冒塔读平台硬性门槛。
- [ ] 场景时空与官方文书的签押、驿递、封存链连贯；不出现无来源物证。
- [ ] 能解决的小危机必须在当章解决，证人带伤、店铺被封、被羁押等代价后续持续存在。
- [ ] 不将草稿、大纲或未采用文字称为“正式第1章”。每章另跑 brief、反向提纲、reader 近似审读和 release-check；采用冻结后不回写正文。
